Supabase Auth & Управление пользователями

                        
Подключение проекта Supabase и добавление/удаление студентов

                    

                

                
            


            
            

                
                
            


            
            

                

                    Укажите Project URL и Anon Public Key из раздела Project Settings → API вашего проекта Supabase. Если поля не заполнены, работает встроенная локальная база пользователей (логин по умолчанию: student / 123456).

Зарегистрированные пользователи

                        
                    

                    

                        
                    

                


                
                

                    Управление через официальную панель Supabase:

                    1. Откройте ваш проект в Supabase Dashboard → Authentication → Users.

                    2. Нажмите Add user → Create new user, введите Email (например, ivan@codepath.local) и пароль, включите Auto Confirm User.

                    3. Чтобы забрать доступ, нажмите на три точки справа от пользователя и выберите Delete user.
